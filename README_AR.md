## 🌟 نظرة عامة (Overview)

**OpenCode Telegram Bridge** هو إضافة خادم رسمية (OpenCode V2 Server Plugin) تمنحك السيطرة الكاملة على وكيلك الذكي (AI Coding Agent) ومتابعة كافة مشاريعك وجلسات العمل على جهاز الكمبيوتر مباشرة من هاتفك عبر تطبيق **Telegram**، أينما كنت.

تم تصميم الإضافة وفق أحدث معايير **OpenCode V2 architecture** لتكون خفيفة، فائقة السرعة، ومستقلة عن نظام التشغيل (تدعم Windows و Linux)، مع التركيز التام على استقرار الاتصال، حماية الخصوصية، وتوفير تجربة مستخدم تفاعلية انسيابية تعتمد على الأزرار المضمنة (Inline Keyboards) الذكية.

## ✨ المميزات الرئيسية (Key Features)

### 💬 تحاور وتوجيه كامل للوكيل (Interactive Agent Chat)
- أرسل أي تعليمات، أكواد، أو أسئلة برمجية مباشرة عبر Telegram وسيقوم الوكيل بتنفيذها على مشروعك المحلي والرد عليك بتنسيق كامل.
- استقبال الردود البرمجية منسقة بكتل الأكواد الملونة والمونو سبيس (Syntax Highlighting).

### ✍️ بث حي لمسودات الكتابة (Live Stream Drafting)
- متابعة مسودة رد الوكيل لحظة بلحظة أثناء توليد الأفكار والتفكير وكتابة الكود دون انتظار انتهاء الاستجابة.
- موازنة وإغلاق وسوم HTML التلقائي لمنع أي تشوه في نصوص البث المباشر.

### 📊 محرك معالجة الجداول الذكي (Smart Markdown Table Engine)
- بما أن Telegram لا يدعم وسوم الجداول (`<table>`)، تم ابتكار محرك تحويل جداول ذكي يدعم 3 أنماط:
  - **`smart` (الافتراضي)**: يحول الجداول الثنائية إلى بطاقات وقوائم نقطية مريحة جداً للهواتف، والجداول الكبيرة إلى جداول Monospace منسقة بحدود أنيقة داخل كتلة كود `<pre>`.
  - **`box`**: رسم الجداول دائماً داخل صندوق كود بأعمدة متساوية ومحاذاة تامة.
  - **`list`**: تحويل الجداول دائماً إلى عناصر وبطاقات نقطية تمنع أي تمرير أفقي.

### 🔐 إدارة الأذونات التفاعلية (Interactive Permissions Gate)
- عندما يطلب الوكيل إذناً لتشغيل أمر في النظام أو تعديل ملفات حساسة، يرسل لك البوت طلباً فورياً بأزرار تفاعلية:
  - `[ ✅ مرة واحدة ]`
  - `[ ♾️ دائماً ]`
  - `[ ⛔ رفض ]`

### 🔄 المزامنة الذكية مع جلسات سطح المكتب (Desktop Sync)
- مزامنة تلقائية لحظية: بمجرد أن تبدأ العمل على أي جلسة في تطبيق OpenCode Desktop، يتزامن Telegram معها تلقائياً.
- زر تفاعلي فوري `[ 🔄 مزامنة مع أحدث جلسة ]` للانتقال للجلسة النشطة بنقرة واحدة.

### ⚡ التحكم في الطاقة وحماية البطارية (Remote Power Guard)
- فحص نسبة شحن البطارية ومصدر الطاقة (موصول بالشاحن أو تفريغ على البطارية).
- ميزة حماية البطارية والإسبات المؤقت (Session-only In-Memory Guard): إدخال الجهاز في وضع الإسبات التلقائي (Hibernate) عند 12% لحفظ عملك وملفاتك المفتوحة، مع إشعار تحذيري مبكر عند 16%.
- زر إسبات يدوي عن بُعد مع تأكيد حماية من الضغط العرضي.
- تصميم مستقل ونظيف (Cross-Platform) يدعم Windows و Linux دون العبث بملفات النظام أو مهام بدء التشغيل التلقائي.

### 🛡️ موثوقية عالية واستعادة تلقائية (Self-Healing Watchdog)
- حلقة استماع محصنة ضد انقطاع الشبكة: تقوم بإعادة الاتصال تلقائياً كل 3 ثوانٍ دون أن تتوقف أبداً.
- قفل موحد مانع لتضارب النسخ (Zero 409 Conflict): يمنع نهائياً تشغيل أكثر من حلقة polling لنفس التوكن على الجهاز.
- استقلالية تامة عن أي أدوات خارجية (مثل emby-dl) وحظر التوكنات المتعارضة برمجياً.

### 🚀 تهيئة سحابية تلقائية للبوت الجديد (Zero-Touch Bot Migration)
- عند تغيير التوكن إلى بوت جديد، يقوم الجسر تلقائياً بحذف أي Webhook قديم، وتسجيل قائمة الأوامر الـ 17 السحابية، وضبط زر القائمة `[ ☰ ]`، وتحديث بروفايل ووصف البوت الترحيبي باللغة العربية، وتصفير إزاحة الرسائل (Offsets) دون أي تدخل يدوي!

### 🧹 واجهة مستخدم مضمنة نقية (Pure Inline UX)
- التخلص الكامل من أشرطة الكيبورد السفلية وكلمة "القائمة" المشوهة في الهواتف، واستبدالها ببطاقات تحكم تفاعلية مضمنة (Inline Cards) تحت الرسائل تحافظ على نظافة الشاشة وحرية حقل الكتابة.

## 🚀 دليل الإعداد السريع خطوة بخطوة

### 1. إنشاء بوت تيليجرام والحصول على التوكن
1. افتح تطبيق Telegram وابحث عن البوت الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot`.
3. اختر اسماً للبوت، ثم اسم مستخدم فريد ينتهي بكلمة `bot` (مثال: `MyOpenCode_bot`).
4. انسخ رمز التوكن (Bot API Token) الناتج.

### 2. تثبيت الإضافة في OpenCode
أضف مسار مجلد الإضافة في ملف التكوين العام لـ OpenCode:
`~/.config/opencode/opencode.jsonc`

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "C:/path/to/integrations/opencode-telegram"
  ]
}
```
*(أو مسار نسبي داخل مشروعك)*.

### 3. إعداد ملف التكوين (`opencode-telegram.json`)
أنشئ ملف الإعدادات في المسار التالي:
`~/.config/opencode/opencode-telegram.json`
*(يمكنك نسخ نموذج `opencode-telegram.example.json`)*:

```json
{
  "token": "ضع_رمز_التوكن_الخاص_بك_هنا",
  "allowedChatIds": [],
  "defaultDirectory": "C:/Users/your-username/Documents/MyProject",
  "liveStream": true,
  "notifyAllSessions": true,
  "tableMode": "smart",
  "pollTimeoutSeconds": 25,
  "debug": false
}
```

### 4. ربط معرّف المحادثة الخاص بك (Chat ID)
1. افتح محادثة البوت الجديد في Telegram واضغط على **Start** أو أرسل `/start`.
2. سيرد عليك البوت برسالة تحتوي على **معرف المحادثة الخاص بك (Chat ID)** مع تنبيه بأن المحادثة غير مصرح لها بعد.
3. انسخ رقم الـ Chat ID وضعه في مصفوفة `allowedChatIds` في ملف `opencode-telegram.json`:
   ```json
   "allowedChatIds": ["1234567890"]
   ```
4. احفظ الملف — **لا تحتاج لإعادة تشغيل OpenCode!** يقرأ البلاجن الإعدادات فوراً ويبدأ بالاستجابة لك.

## ⚡ نظام التحكم بالطاقة وحماية البطارية

تتضمن الإضافة وحدة طاقة مستقلة ونظيفة (`power.ts`) تدعم أنظمة التشغيل المتعددة:

- **فحص مستوى الطاقة**:
  - **على Windows**: استعلام خفيف عبر API النظام المباشر.
  - **على Linux**: قراءة مباشرة من أنوية `/sys/class/power_supply/`.
- **حماية البطارية عند 12% (In-Memory Guard)**:
  - لا يتم تثبيت أي برامج بدء تشغيل أو مجدول مهام على نظامك إطلاقاً.
  - يتم تفعيل الميزة لمرة واحدة بطلبك عبر Telegram (`/power` ثم زر التفعيل).
  - عند انخفاض البطارية إلى **16%** على البطارية: إشعار تحذيري مبكر لتوصيل الشاحن.
  - عند وصولها إلى **12%**: إشعار عاجل عبر تيليجرام وإدخال الجهاز في وضع **الإسبات الكامل (Hibernate)** لحفظ جميع النوافذ والبرامج المفتوحة واسترجاعها بدقة عند إعادة التشغيل.
  - عند إعادة تشغيل الكمبيوتر، تعود الميزة لوضع الإيقاف تلقائياً دون أي أثر دائم في النظام.

## ⚙️ ملف الإعدادات والاستكشاف التلقائي (Configuration & Auto-Discovery)

يدعم الجسر ميزة **الاستكشاف التلقائي الذكي لمسار الإعدادات**، حيث يمكنك وضع ملف الإعدادات في أي من المسارات التالية حسب رغبتك:

1. **داخل مجلد المشروع مباشرة (محلي)**:
   - `./opencode-telegram.json` أو `./.opencode/opencode-telegram.json` *(مناسب جداً للنماذج والمشاريع المستقلة المحمولة)*.
2. **في مجلد إعدادات المستخدم العام (عالمي)**:
   - `~/.config/opencode/opencode-telegram.json` *(يطبق على كافة المشاريع في جهازك)*.
3. **عبر متغيرات البيئة (Environment Variables)**:
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_CHAT_IDS`

> 💡 **الإنشاء التلقائي للقالب**: إذا لم يجد البلاجن أي ملف إعدادات عند أول تشغيل، فإنه يقوم تلقائياً بإنشاء ملف قالب جاهز في `~/.config/opencode/opencode-telegram.json` ويطبع إشعاراً واضحاً في السجل يوضح مكان الملف وكيفية تعبئته.

```jsonc
{
  // رمز التوكن السري المستخرج من BotFather
  "token": "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz",

  // قائمة معرفات المحادثات المصرح لها بالتحكم (لحمايتك من أي وصول خارجي)
  "allowedChatIds": ["1234567890"],

  // المسار الافتراضي لفتح الجلسات الجديدة
  "defaultDirectory": "C:/Users/username/Projects/MyProject",

  // تفعيل بث مسودات الكتابة أثناء تفكير الوكيل لحظياً
  "liveStream": true,

  // إرسال إشعارات بكل ما يتم تنفيذه في OpenCode Desktop حتى لو بدأ من الكمبيوتر
  "notifyAllSessions": true,

  // نمط عرض الجداول: "smart" (ذكي) أو "box" (صندوق مونو سبيس) أو "list" (بطاقات نقطية)
  "tableMode": "smart",

  // مسار أو أمر تشغيل بايثون (اختياري)
  "pythonCommand": "python",

  // مهلة الانتظار لطلب Long-polling بالثواني
  "pollTimeoutSeconds": 25,

  // تفعيل السجلات التفصيلية للتصحيح والتتبع
  "debug": false
}
```

## 🔒 الأمان والخصوصية (Security & Privacy)

1. **التحقق الصارم من المعرفات (Chat ID Whitelist)**: لا يتم قبول أي أمر أو رسالة من أي مستخدم غير مضاف في `allowedChatIds`. أي محادثة غير معروفة تتلقى معرّفها فقط مع رفض التنفيذ.
2. **عزل التوكنات التام**: ملف الإعدادات يقع خارج مستودع الكود (`~/.config/opencode/`)، ومدرج في `.gitignore` لضمان عدم رفعه بالخطأ.
3. **فحص أمان emby-dl**: يحظر الكود استخدام توكنات مشاريع أخرى مثل emby-dl لمنع التداخل والتعارض.
